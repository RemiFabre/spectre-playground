# the Spectre, an aperiodic monotile playground

Interactive tiling of the [Spectre](https://arxiv.org/abs/2305.17743) (Smith, Myers,
Kaplan & Goodman-Strauss, 2023), the single shape that tiles the plane but only
aperiodically.

Guided mode only offers placements that provably extend to a perfect, hole-free
tiling; local mode lets you discover the dead ends yourself; free mode has no rules.
Paint tiles with the color brush, replay any build like sheet music, and publish
your shape by name to the public gallery
([RemiFabre/spectre-shapes](https://huggingface.co/datasets/RemiFabre/spectre-shapes)).
How it works, with each mathematical claim labelled: see the site's `about.html`.

Source, tests and full documentation:
[github.com/RemiFabre/spectre-playground](https://github.com/RemiFabre/spectre-playground).
